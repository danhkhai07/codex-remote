    App tự quản lý cache. Server xác thực lại trước khi browser dùng nội dung đã lưu.

    ciphertext · revalidate
    • Khóa chỉ ở bộ nhớ trong lúc mở khóa.

    Những điểm dễ nhầm

    no-cache khác no-store thế nào?

    no-cache vẫn cho phép lưu, nhưng phải kiểm tra lại trước khi dùng. no-store yêu cầu không lưu response trong HTTP cache. App vẫn có thể quản lý một kho bản mã riêng trong IndexedDB; kho đó được kiểm soát bằng logic ứng dụng.

    Reload có tải lại mọi thứ không?

    Reload cần mở khóa lại. Các mục API hợp lệ có thể dùng lại sau xác thực và kiểm tra phiên bản. Nội dung đổi thì nhận bản mới. Ctrl+Shift+R có thể bỏ qua HTTP cache, nhưng không đồng nghĩa xóa IndexedDB; app vẫn thực hiện kiểm tra lại.

    Lock, logout và đổi khóa khác nhau ra sao?

    Lock: ẩn UI riêng, bỏ tham chiếu khóa trong RAM và dừng transport; giữ cache bản mã. Logout: còn thu hồi phiên và cố gắng xóa cache của app. Đổi khóa: vô hiệu kênh/namespace cũ. Những job đã nhận trên VPS vẫn tiếp tục.

    Cache có làm giảm tải server không?

    Chủ yếu giảm bytes gửi lại đến browser. Server vẫn kiểm tra quyền và nội dung hiện tại; proxy preview vẫn đọc upstream và tính hash. Không mặc định giảm mọi truy vấn, CPU hoặc thời gian chờ.

    Cloudflare có đọc được hết dữ liệu không?

    Trong thiết kế này, payload API riêng tư được mã hóa thêm giữa browser và VPS. Nhưng HTTPS, HTML/JS khởi động, đăng nhập và preview không tự có lớp mã hóa đó. Nếu JavaScript được gửi tới browser bị thay đổi chủ động, lớp bảo vệ này không giải quyết được.

    Phạm vi bảo vệ

    • Cần cả phiên đăng nhập hợp lệ + khóa riêng + quyền tài nguyên. Biết URL API hoặc có file cache không đủ để sử dụng dữ liệu riêng.
    • Mã hóa bảo vệ nội dung API khi truyền và bản cache trên thiết bị. Browser đang mở khóa và VPS vẫn cần đọc dữ liệu để xử lý.
    • Không chống được root/VPS bị chiếm quyền, XSS khi đang mở khóa hoặc mã frontend bị thay thế.
    • Không tự mã hóa toàn bộ ổ đĩa, lịch sử trên server, draft cũ hay file đã tải xuống. Không phải mã hóa đầu cuối tới nhà cung cấp model.
    • Thu hồi quyền chặn truy cập tiếp theo; không thể lấy lại bytes hay ảnh chụp mà người dùng đã nhận.

    Nếu cache lỗi, hết hạn hoặc thiếu: tải lại bằng một lượt đọc có quyền. Không tự gửi lại thao tác ghi khi chưa biết kết quả.
